# 무력 포커 (Show Poker)

클래시 로얄(Clash Royale) 유닛 카드를 활용한 **8인 1대1 싱글 엘리미네이션 포커 & 친선전 토너먼트** 웹 애플리케이션입니다.

## 1. 공식 게임 규칙 ([무력 포커])

- **참가 인원 및 방식**: 8명 참가 / 1대1 토너먼트 (8강 ➔ 4강 ➔ 결승)
- **초기 자원 및 배분**:
  - 각 매치 첫 게임 시작 시 두 참가자는 **100골드**를 보유하며, 매 라운드 **5장씩 카드**를 배분받습니다.
- **기본 베팅 및 초기 공개**:
  - 매 라운드 시작 시 양측 모두 **기본 베팅금 10골드**를 테이블(팟)에 올리고, **각자 카드 1장씩을 공개**하고 시작합니다.
- **선 베팅 순서**:
  - **첫 게임(ROUND 1)**은 **점수가 높은 쪽**(참가자 입력 점수/트로피 기준, 미입력·동점 시 첫 공개 카드의 무력 점수 기준)이 선 베팅합니다.
  - **이후 게임(ROUND 2~)**부터는 매 라운드 **번갈아 선 베팅**합니다.
- **베팅 / 콜 / 폴드 진행 규칙**:
  - **베팅(Bet/Raise)**: **10골드 단위**로만 가능하며, **직전의 상대 베팅금보다 높게만** 베팅할 수 있습니다. 베팅할 때마다 본인의 비공개 카드를 1장씩 공개합니다. (선언한 베팅금만큼 보유 골드에서 차감되어 테이블 팟에 누적됩니다.)
  - **콜(Call)**: 직전 상대의 베팅금만큼 골드를 지불하고(**베팅금이 모자라도 잔여 골드 전액으로 올인 콜 가능**) 본인의 카드를 1장 공개한 뒤, **서로의 5장 패를 모두 공개**하고 그 5장만을 사용하여 상대와 **친선전**을 진행합니다. 친선전에서 이긴 쪽이 서로의 베팅금(팟 전체)을 모두 획득합니다.
  - **폴드(Fold)**: 베팅을 포기하며(본인의 카드 1장 공개 후 폴드 또는 즉시 폴드 가능), 테이블에 올라간 베팅금은 상대가 모두 획득합니다.
- **탈락 및 토너먼트 진출**:
  - 라운드 정산 후 **보유 골드가 0이 되면 즉시 탈락**하며, 승리한 참가자가 다음 토너먼트 라운드(4강 / 결승)로 진출합니다.

### 베팅 진행 예시
A와 B가 둘 다 100골드를 보유한 상태에서 포커 시작 (첫 게임은 점수 높은 쪽이 선 베팅, 이후 번갈아 선 베팅):
1. **A (100 ➔ 90골드)**: (10골드 기본 베팅) `"삼총사"` 공개
2. **B (100 ➔ 90골드)**: (10골드 기본 베팅) `"해골 병사"` 공개
3. **A (90 ➔ 80골드)**: `"10골드, 나무꾼"` 공개
4. **B (90 ➔ 70골드)**: `"20골드, 박쥐"` 공개
5. **A (80 ➔ 40골드)**: `"40골드, 통나무"` 공개
   - **케이스 1 — B가 콜을 선택한 경우**:
     `B (70 ➔ 30골드): "콜, 발키리" (40골드)`
     ➔ A와 B가 서로의 5장 패를 모두 공개한 후 친선전 진행, 승자가 총 130골드 팟 전액 획득
   - **케이스 2 — B가 폴드를 선택한 경우**:
     `B (70골드): "폴드"`
     ➔ A가 자신의 베팅금(기본10+10+40=60골드)을 돌려받고 B의 베팅금(기본10+베팅20=30골드)을 획득하여 **40 ➔ 130골드** 보유 (시작 대비 100 ➔ 130골드)

## 2. 프로젝트 폴더 및 파일 구조

- `index.html`: 로비, 8인 토너먼트 대진표 브래킷, 1:1 포커 아레나 테이블, 카드 지급/공개/쇼다운/도감 모달 UI
- `database.rules.json`: Firebase Realtime Database 보안 규칙 설정 파일
- `css/style.css`: 아레나 테마, 글래스모피즘, 3D 액션 버튼 및 실시간 배지 애니메이션 스타일
- `css/cards.css`: 클래시 로얄 스타일 카드 프레임(일반/희귀/영웅/전설/챔피언), 부채꼴 손패 및 반응형 레이아웃
- `js/game-engine.js`: `[무력 포커]` 핵심 상태 머신 (`MatchEngine` - 기본 베팅, 선공 결정, 10단위 베팅/콜/폴드, 카드 공개 및 정산)
- `js/tournament.js`: 8인 1:1 토너먼트 브래킷 생성, 승자 진출 및 다음 활성 매치 탐색 모듈
- `js/app.js`: Firebase 실시간 멀티플레이어 동기화, AI 봇 대전, UI 렌더링 및 이벤트 컨트롤러
- `js/cards-data.js`: 클래시 로얄 전투 카드 119종 데이터 및 무작위 중복 방지 덱 추첨 유틸리티
- `js/battle-sim.js`: 5 vs 5 카드 상성·시너지 기반 웹 자동 무력 대결 시뮬레이터
- `js/crypto-security.js`: Web Crypto API(`SHA-256`) 기반 카드 커밋먼트 생성 및 위변조 검증 모듈
- `js/firebase-config.js`: Firebase Realtime Database & 익명 인증 초기화 및 연결 관리
- `js/sound.js`: Web Audio API 신디사이저 기반 효과음 시스템
